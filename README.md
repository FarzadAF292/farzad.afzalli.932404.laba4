## Описание

В данной лабораторной работе к странице из предыдущих лабораторных работ был добавлен JavaScript.
Основная цель работы — изучение базового синтаксиса JavaScript, работы с массивами, условиями, циклами и функциями.

## Реализовано

В работе реализованы:

- подключение внешнего файла `script.js`;
- ввод имени пользователя с помощью `prompt()`;
- вывод приветствия через `alert()`;
- вывод информации в консоль с помощью `console.log()`;
- массив с данными о дневной выручке;
- поиск максимальной дневной выручки;
- фильтрация дней с высокой выручкой;
- подсчёт общей выручки;
- подсчёт дней с низкой выручкой;
- расчёт доли дней с низкой выручкой;
- расчёт средней дневной выручки;
- использование условной конструкции `if`;
- использование циклов;
- использование функций для основной логики программы.

## Данные варианта

Для анализа используется массив дневной выручки в рублях.
Высокой считается выручка более `10 000 ₽`.
Низкой считается выручка `3 000 ₽` или меньше.
Если средняя дневная выручка меньше `5 000 ₽`, в консоль выводится дополнительное сообщение о необходимости проанализировать причины низкой выручки.
